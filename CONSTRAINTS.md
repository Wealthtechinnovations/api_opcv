- une application logique, deux historiques Git indépendants ;
- branches canoniques existantes uniquement ;
- pas de nouvelle branche de travail automatique ;
- pas de force-push/réécriture d’historique ;
- single writer par scope ;

- GitHub autorité du code/documentation ;
- S2 projection/runtime, pas autorité Git ;
- données financières non inventées ;
- migrations destructives interdites sans décision explicite ;
- documentation et preuves intégrées au changement.
