# SCOPE — AfricaFunds API

Le scope de ce dépôt couvre le backend AfricaFunds : API, services, modèles, migrations, calculs financiers, imports, normalisation, crons, workers, contrôles de données et documentation backend.

Le frontend, l’UX et le SEO sont autoritaires dans `front_end_opcvm`, mais tout contrat partagé impose une analyse cross-repository.

La gouvernance Regulatory Plus s’applique aux humains, IA, automatisations et outils intervenant sur ce dépôt.
