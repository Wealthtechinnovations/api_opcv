# PROJECT_BRIEF — AfricaFunds

AfricaFunds est une plateforme d’analyse et de sélection de fonds africains. Le produit public est `https://africafunds.chainsolutions.fr` et l’API publique est exposée sous `/api`.

L’objectif de gouvernance est de permettre à plusieurs humains/IA de travailler de manière synchronisée, reproductible et sans régression sur deux dépôts Git indépendants, avec une mémoire persistante dans Git et des preuves vérifiables.
