# DEFINITION_OF_READY — AfricaFunds

Un lot est READY si son objectif, scope, autorités, API_HEAD, FRONTEND_HEAD, checkpoint global, dépendances, impacts, writer, contrôles attendus, données affectées et stop conditions sont connus.

Un lot n’est pas READY si une source de vérité est ambiguë, si un conflit de writer existe, si une migration destructive manque d’approbation ou si le contexte Git est périmé.
