# ASSUMPTIONS — AfricaFunds

Une hypothèse n’est jamais une vérité.

Toute hypothèse utilisée dans un lot doit indiquer : contexte, raison, moyen de vérification, impact si fausse et date/lot. Les données financières, états de production, sources, résultats de tests et permissions ne doivent jamais être supposés lorsqu’ils peuvent être observés.

Les hypothèses non résolues qui bloquent une décision doivent être portées dans `OPEN_QUESTIONS.md`.
