# LOOP_ENGINEERING_MASTER_STANDARD — AfricaFunds

Le standard maître formalise la continuité humaine/IA : observer, réconcilier, établir la baseline, sélectionner un lot, analyser les impacts, vérifier les deux HEAD, acquérir le single writer, implémenter compatiblement, vérifier, contrôler les régressions, persister les preuves, committer, vérifier le remote, déployer si autorisé, attester la production et sélectionner la suite.

`LOOP_ENGINEERING.md` reste l’adaptation opérationnelle détaillée AfricaFunds. Ce fichier n’en crée pas une seconde version ; il en rappelle les invariants transversaux.
