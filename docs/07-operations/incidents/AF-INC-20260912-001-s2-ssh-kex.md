# AF-INC-20260912-001 — SSH S2 resets KEX

**Statut : RCA_PENDING — SEV2**

Mesure historique : 8 connexions réussies / 3 échecs sur un échantillon, avec reset avant authentification au niveau key exchange.

## Mécanisme — PROVEN
Reset intermittent du canal SSH avant authentification.

## Root cause — UNKNOWN
Aucune attribution définitive réseau/sshd/amont n'est prouvée.

## Impact
Les opérations d'observation/attestation peuvent échouer alors que S2 reste sain.

## Action
`AF-OPS-004` doit ajouter un retry borné uniquement sur les chemins read-only et seulement pour des erreurs pré-auth transitoires. Une mutation distante ne doit jamais être répétée automatiquement si son exécution est ambiguë.
