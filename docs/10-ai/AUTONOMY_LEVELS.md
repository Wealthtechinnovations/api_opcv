# AUTONOMY_LEVELS — AfricaFunds

- `L0 READ` : lecture/analyse.
- `L1 RECONCILE` : comparaison d’états.
- `L2 VERIFY` : tests/checks read-only.
- `L3 PERSIST` : registres/documents dans scope autorisé.
- `L4 CHANGE` : écriture bornée single-writer.
- `L5 DEPLOY` : autorisation distincte.
- `L6 ATTEST` : mesures post-déploiement.

Un niveau n’accorde jamais implicitement le suivant.
