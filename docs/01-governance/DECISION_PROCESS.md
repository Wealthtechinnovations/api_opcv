# DECISION_PROCESS — AfricaFunds

Une décision structurante est fondée sur des faits observés, compare les alternatives, décrit impacts/risques/migration/rollback et est persistée dans `docs/DECISIONS.md` avec ADR si nécessaire.

Les décisions historiques ne sont pas réécrites pour correspondre au présent. Une nouvelle décision supersède explicitement l’ancienne avec traçabilité.
