# ESCALATION_POLICY — AfricaFunds

Escalade obligatoire si : conflit d’autorité ; writer concurrent ; HEAD inattendu ; migration destructive ; secret/exposition sensible ; données financières non vérifiables ; régression inexpliquée ; production contradictoire ; artefact runtime `UNKNOWN` à détruire ; changement de gouvernance/branche/source de vérité.

Dans ces cas : `WRITE_GATE=CLOSED` jusqu’à décision/proof suffisante.
