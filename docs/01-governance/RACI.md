# RACI — AfricaFunds

| Activité | Responsable opérationnel | Approbation |
|---|---|---|
| analyse/lecture | humain ou agent autorisé | aucune si read-only |
| écriture bornée | single writer gouverné | selon scope |
| gouvernance structurante | writer + documentation | propriétaire projet |
| migration destructive | équipe technique | approbation explicite propriétaire |
| production | opérateur autorisé | autorisation distincte du code |
| données financières sensibles | expert/data owner | revue adaptée |

Les identités nominatives peuvent évoluer ; les rôles restent canoniques.
