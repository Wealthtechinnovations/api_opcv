# EXCEPTION_REGISTER — AfricaFunds

Aucune exception active n’est supposée.

Toute exception doit indiquer : ID, règle concernée, justification, scope, propriétaire, date d’effet, expiration, contrôles compensatoires, preuve d’approbation et condition de retour à la règle normale.

Une urgence ne crée pas automatiquement une exception permanente.
