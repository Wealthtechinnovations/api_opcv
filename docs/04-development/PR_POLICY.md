# PR_POLICY — AfricaFunds

Le modèle courant autorise le travail normal sur la branche canonique existante et n’impose pas de PR par défaut. Toute évolution vers PR obligatoire/ruleset doit être auditée et approuvée avant enforcement. Les revues peuvent néanmoins utiliser PR lorsque le workflow/owner le demande. Aucun bypass silencieux.
