# COMMIT_CONVENTION — AfricaFunds

Commits atomiques décrivant le résultat. Préfixes recommandés : `docs:`, `feat:`, `fix:`, `refactor:`, `test:`, `data:`, `ops:`, `chore:`. Un commit ne doit pas mélanger correction et refonte sans lien, ni contenir secret/donnée sensible. La documentation nécessaire appartient au même lot logique.
