# CODING_STANDARDS — AfricaFunds API

Suivre les conventions réellement présentes dans le code. Préférer changements petits, lisibles, testables, compatibles et sans duplication. Validation d’entrées, erreurs explicites, absence de secrets, fonctions/services cohérents avec l’architecture existante. Aucun refactoring non lié ne doit être mélangé au lot.
