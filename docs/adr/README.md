# ADR — AfricaFunds

Les ADR détaillent les décisions structurantes sans réécrire l’historique. Le registre synthétique reste `docs/DECISIONS.md`.

Chaque ADR doit contenir : contexte, décision, alternatives, conséquences, risques, compatibilité/migration, rollback si applicable et preuves.

Ne jamais réutiliser un identifiant existant pour une autre décision.
