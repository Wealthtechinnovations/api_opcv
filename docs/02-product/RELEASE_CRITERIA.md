# RELEASE_CRITERIA — AfricaFunds

Une release est admissible si les critères fonctionnels sont satisfaits, les tests applicables passent, les données/calculs concernés sont contrôlés, les dépendances API/frontend sont compatibles, la sécurité pertinente est vérifiée, le rollback est compris et le nouvel état distant est attesté. Production exige en plus mesure S2/runtime.
