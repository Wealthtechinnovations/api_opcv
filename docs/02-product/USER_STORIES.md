# USER_STORIES — AfricaFunds

Les user stories doivent être reliées à une fonctionnalité existante ou à une tâche gouvernée, avec critères d’acceptation mesurables. Une story n’est jamais une preuve d’implémentation.

Rôles génériques : investisseur/épargnant, professionnel/analyste, SGO/gestionnaire, administrateur/data operator, intégrateur API. Toute spécialisation doit être vérifiée contre l’application réelle.
