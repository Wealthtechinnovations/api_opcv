# PRODUCT_VISION — AfricaFunds

AfricaFunds vise une plateforme fiable d’analyse, comparaison et sélection de fonds africains, appuyée sur des données traçables, des calculs reproductibles et une expérience cohérente.

La gouvernance doit accélérer l’évolution sans sacrifier les données, les historiques, les contrats API, l’UX ni la production existante.
