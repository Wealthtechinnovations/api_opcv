# SECURE_EVIDENCE_STORAGE — AfricaFunds

Les preuves versionnables non sensibles peuvent vivre dans Git. Secrets, données personnelles, dumps et artefacts volumineux/sensibles doivent rester dans leur stockage autorisé avec seulement référence, hash, date, producteur et politique de rétention dans Git.

Ne jamais committer un secret pour rendre une preuve autonome.
