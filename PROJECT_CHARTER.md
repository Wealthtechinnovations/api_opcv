# PROJECT_CHARTER — AfricaFunds Governance

## Mandat

Faire évoluer AfricaFunds par intégration complète dans l’existant, sans architecture parallèle ni perte d’histoire.

## Principes

1. vérité et preuves avant supposition ;
2. réutilisation avant création ;
3. compatibilité avant migration ;
4. single writer et double HEAD ;
5. documentation dans le même changement ;
6. production attestée seulement après mesure ;
7. décisions durables versionnées.
