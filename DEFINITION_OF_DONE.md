# DEFINITION_OF_DONE — AfricaFunds

`CODE_WRITTEN != DONE` et `DOC_WRITTEN != DONE`.

Un lot est DONE seulement si : résultat atteint, historique préservé, contrôles applicables passés, non-régression vérifiée, données/contrats cohérents, HEAD distants réobservés, mémoire persistante synchronisée, limitations déclarées, production vérifiée si touchée et prochaine action unique enregistrée.
