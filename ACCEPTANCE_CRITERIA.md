# ACCEPTANCE_CRITERIA — AfricaFunds Governance

Le chantier Regulatory Plus est acceptable si :

- les capacités génériques manquantes sont intégrées ;
- les canons historiques sont conservés ;
- aucun fichier existant utile n’est supprimé ou remplacé par commodité ;
- les rôles `SUIVI`, `STATUS`, `WORK_LOG`, `LOOP_STATE`, `CURRENT_ITERATION`, `HANDOFF`, `NEXT_ACTION` restent distincts ;
- les deux HEAD sont réobservés ;
- les checks disponibles sont exécutés ;
- les contradictions sont documentées ;
- les preuves et la prochaine action sont persistées ;
- aucun état production n’est déclaré sans mesure.
